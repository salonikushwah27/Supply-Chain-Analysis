# Supply Chain Analysis – Late Delivery Dashboard

## Goal
This project finds out **why late deliveries are happening** in the supply chain, using Power BI.

## Problem I Solved
Late deliveries were hurting **customer trust**. With 173K total orders and 95K late deliveries (54.71% late delivery rate), customers were not getting orders on time. I analyzed the data by region, shipping mode, category, customer segment, and order status to find exactly where and why delays were happening.

## Key Findings
- Central Africa and Southeast Asia have the highest late delivery%.
- Standard Class shipping has the most late deliveries.
- Payment and Transfer type orders are more delayed than Cash/Debit.
- Late delivery% stays high (around 54%) almost every month.

## What Company Can Improve
- Improve shipping in high-delay regions.
- Reduce use of Standard Class; promote First/Second Class shipping.
- Speed up payment processing (avg 3.47 days) to reduce delays.
- Set alerts when late delivery% crosses a limit.
- Track on-time delivery% monthly to measure improvement.

## Tools Used
Python, Power BI, DAX, Power Query
